📘 Syntax Cheat Sheet
  • Arguments: Defined inside `{}` brackets. The engine automatically numbers them starting at 1. (e.g., Arg 3 is `n/p`).
  • Label Anchor: Direction letter (e.g., B for Bottom, L for Left) OR custom shifted coordinates like 0 3.5 B (Shift X=0, Shift Y=3.5, Anchor=B).
  • Scales: Comma separated list of allowable scales (e.g., 1, 2, 4).
